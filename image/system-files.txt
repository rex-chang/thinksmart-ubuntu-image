# The system layer: every file of this repository that goes onto the device, where it goes and what
# has to restart when it changed. image/device-setup.sh files installs from it, and so does an
# online update (update/thinksmart-update), which backs up every destination first and puts the
# backup back if the restarted services don't come up. Nothing outside this table is touched by an
# update (kernel, boot partition, apt packages, user data).
#
# SOURCE  DESTINATION  MODE  OWNER  ON-CHANGE (comma separated)
#   SOURCE -       a file system-post.sh edits in place: backed up and compared, not installed
#   kiosk          restart the screen (thinksmart-kiosk.service: Weston and the browser)
#   mic            restart thinksmart-mic and the client
#   wireplumber    stop thinksmart-mic, restart WirePlumber, start thinksmart-mic, restart the client,
#                  volume put back (README 3.4); pipewire: the same with PipeWire itself
#   bluetooth      restart bluetooth.service
#   system:UNIT / user:UNIT   restart that unit (of the system / of user ubuntu)
#   boot           read only at boot: "takes effect after a restart" on the page
#   updater        this updater: the new copy must pass `thinksmart-update selftest`
#   keep           user configuration: installed only if missing, never overwritten
#   none           nothing to restart
# Unit files also get a daemon-reload. Files a version drops from this table are removed.
# require PACKAGE: an apt package the layer needs; a device without it is told to reflash.
